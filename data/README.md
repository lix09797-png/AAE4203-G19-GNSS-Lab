# Data archives

The GNSS archive contains the original G19 field logs, complete regenerated RINEX, course example and benchmark observation/navigation data, observation-derived CSV caches and recomputed RTKLIB comparison positions. The tools archive contains the course-supplied Windows MatRTKLIB/RTKLIB utilities and their original licence notices.

Run `python -B reproduce.py` from the repository root to verify the archive and member SHA-256 hashes, extract the files and regenerate both trajectory CSVs. See `manifest.json` for every archived path and checksum.
